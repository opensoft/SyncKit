# SyncKit — RETIRED

**Retired 2026-09-04.** Ruled by Brett Heap: SyncKit is no longer used and
receives no further development. See issue #1.

What it was: a WSL ↔ OneDrive bidirectional sync for a projects tree, run from
`~/.local/bin` on a schedule. The code, its README and the architecture notes
are on the [`oneDrive`](../../tree/oneDrive) branch; `main` holds only the
original `PRD.md`.

What was not carried forward: a workstation fork of
`dataSync/scripts/wsl-bidirectional-sync.sh` (November 2025) that added
home-directory dotfiles sync. It matched no commit here, last ran in December
2025, and was abandoned rather than ported. It is not in this repository.

This repository is kept as a record and is a candidate for archiving.
